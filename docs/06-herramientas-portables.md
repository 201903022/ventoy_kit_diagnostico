# 6. Herramientas portables opcionales (Windows)

Se copian a la carpeta `Herramientas/` de la USB y se usan desde Hiren's BootCD PE o desde cualquier Windows. Descárgalas siempre de la página oficial.

| Herramienta | Página | Para qué sirve en este kit |
|---|---|---|
| WinDirStat | <https://windirstat.net/> | Ver qué ocupa espacio en un disco (mapa de colores). Útil antes de respaldar o al decidir el tamaño de un disco nuevo. Es de código abierto (GPL). Revisa su página de descargas para ver la versión portable. |
| NirSoft | <https://www.nirsoft.net/> | Colección de utilidades gratuitas y pequeñas. Útiles: **BatteryInfoView** (estado de batería), **USBDeview** (dispositivos USB), **DriverView** y **DevManView** (drivers y administrador de dispositivos). |

## Notas

- La mayoría de las utilidades de NirSoft se descargan como `.zip` y funcionan sin instalar.
- Algunos antivirus marcan como sospechosas las herramientas de NirSoft que recuperan contraseñas. Para este kit **no las necesitas**; usa solo las de hardware.
- **No** pertenece a este kit: CyberDrain (<https://www.cyberdrain.com/>) es una comunidad y software para administrar Microsoft 365 en empresas, no sirve para diagnosticar hardware.
- Para quien prefiere quedarse solo en Linux, `ncdu` (en SystemRescue y Fedora) cumple una función parecida a WinDirStat.
